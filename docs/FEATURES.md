# 2.0 交付范围

- 公众首页：紫金星夜、留白、轻动态、手机导航、减少动态偏好与键盘焦点。
- 塔罗：78 张牌，单张 / 三张牌阵，正逆位，基础解读与复制。
- 易经：三枚硬币法，六爻由下而上展示、本卦、变卦与动爻。
- 访客探索：临时本机体验；登录后保存到云端。
- 账户：邮箱注册 / 验证 / 登录 / 退出 / 密码重设、TOTP 与一次性恢复码、账户删除。
- 云端记录：本人列表、分页、详情、删除、主动共享与停止共享。
- 每日星笺：按上海日期跨设备同一张正位牌，编辑提示、心情与 600 字私人日记；支持过去星笺编辑与并发冲突提示。
- AI：可配置 OpenAI 兼容 HTTPS 服务，包括 DeepSeek；引用校验、明确同意、30 秒超时、100KB 响应限制、共享限流、全站持久日请求预算、最多 4 个并发调用。
- 管理：汇总与依赖状态、基本用户信息、停用/恢复普通账户、共享记录、无正文操作日志。
- 数据控制：导出全部占卜与全部星笺 / 日记；日记界面展示最近 90 条，数据库保留更早条目至删除账户。
- 交付：源码 PR、锁文件与 SQL 迁移、自动测试、Docker Compose、国内部署与备份恢复指南。

支付、短信、小程序、社交登录、客服聊天、自动模型工具调用未列入此次功能范围；引入前需独立设计和验证。真实模型、SMTP 与正式服务器需要运营者配置，不在源码中伪造生产服务成功。

传统卦象反思与每日信件是本项目整理的提示，不宣称完整经文校勘。牌面目前采用符号与原创 CSS 布局；没有未经授权复制商业牌组。
