# 全面功能版交付范围

## 占卜与学习

- 塔罗：原78牌与正逆位；32牌阵，涵盖关系、事业、选择、学习、自我探索、周月与全年，牌阵各位置有独立含义。
- 15主题场景、推荐问题、牌阵筛选和位置说明；洗牌、逐张翻牌与全部翻开，动画尊重减少动态偏好。
- 易经：三硬币、数字、上海公历时间三种起卦；六爻、本卦、变卦、动爻、互卦、错卦、综卦。
- 数字和时间方法展示规则与来源，支持复现；时间法为当代公历简化法，不宣称农历梅花法。
- 图鉴：78张牌与64卦，可检索、分类、详情；循序入门教程。
- AI初次解读与围绕同一次结果的连续追问；固定引用、明确同意、请求幂等、持久预算与每人额度。
- 浏览器生成分享PNG海报，默认不包含问题、日记、私人备注或AI追问；可主动包含问题。无外部牌图请求。

## 个人星空

- 预创建用户名/密码登录、离线初始化/旧账号用户名分配/密码重设、退出、TOTP与一次性恢复码、账号删除；关闭公开注册与所有邮件认证入口。
- 云端记录分页、搜索、类型/日期/收藏/标签筛选；收藏、8个标签、1000字私人备注，版本冲突保护。
- 每日星笺、五种心情、600字日记；上海日界唯一领取，历史日期与月历浏览、分页加载旧日记、未保存提醒。
- 周/月统计与本地反思；主动请求AI回顾，日记默认不发送，需额外勾选。
- 行动计划、关联占卜、期限、完成状态、修改与删除；本人归属、私密加密和版本冲突。
- 全关联数据导出：占卜、日记、追问、回顾、行动、反馈与会员信息；不导出密码或TOTP秘密。

## 管理、运营与会员

- 管理后台：基本用户信息、停用恢复、共享占卜、无正文审计、30/90天趋势和服务状态。
- 管理员不读取私人日记、标签、备注、追问或行动；反馈是用户主动提交给运营者的内容。
- 纯文本内容与公告的草稿、发布、编辑、版本校验；公众仅能看已发布内容。
- 本人反馈列表、分类提交、管理员回复与状态处理；回复在站内显示，不自动向别人发送邮件。
- 免费/Plus每日AI额度、会员到期、积分余额、兑换码、真实额度明细；并发消费和兑换有事务保护。
- 现金支付尚未开放：未有商户授权与配置，不创建虚假付款成功记录；后续真实接入需独立验证支付签名与订单回调。

## 交付和部署

- React与NestJS独立镜像，MySQL8.4/Redis7.4，增量SQL迁移，HTTPS网关与私网数据库。
- PWA清单、安装入口与iPhone操作说明；缓存只包含公开静态外壳，不包含API或私人内容。实际安装需HTTPS。
- 响应式桌面/iPhone/320px；安全测试、真实数据库验证、浏览器流程、加密备份恢复。
- GitHub分支/PR可review；完整版上线仍需服务器、域名、预创建账户、模型凭据和真实环境验收。

新增体系如六爻纳甲排盘、农历梅花、奇门、八字不属于这次三种起卦的实现，不会用简化算法冒充它们。牌面采用原创几何视觉与已授权文字资料。
