# MVP review

## 优先体验

1. 手机进入首页，输入一个问题；塔罗与易经可切换，题目保留。
2. 三张抽牌：逐张或一次翻开，查看基础解读；重新打开记录时牌面保持一致。
3. 单张抽牌与关闭逆位：检查数量及正位显示。
4. 易经：连续抛六次，从下向上生成爻；6/9 是动爻，页面展示本卦与变卦。
5. AI 配置后：请求解读、重试、追问；上述操作不重新抽牌或起卦。
6. 历史记录：刷新后重看、删除单条、清空；复制在剪贴板不可用时提供可选择的文字。
7. 系统减少动态效果、手机与桌面宽度、键盘焦点和错误状态。

## 验证来源

纯 JavaScript 核心已在当前工具运行时检查：78 张唯一牌、抽牌无重复、硬币 1:3:3:1 概率、文王卦序已知样例、全部 4096 种六爻组合，以及前端与 API 的语法。

GitHub Actions 运行 Node 核心/API 测试、Sites Worker 构建及 Chromium/WebKit UI 流程。实际状态以本 PR 的 checks 为准，不能仅凭工作流文件存在认定通过。

浏览器截图下载位置：成功或部分运行后的 Actions → Verify MVP → Artifacts → ui-screenshots。AI 和追问检查使用模拟响应；没有配置或验证真实模型密钥。

## 当前边界

- 牌面是符号设计；56 张小阿卡纳使用花色与阶位组合关键词。
- 易经解读是现代主题提示，无完整卦辞/爻辞。
- 本机记录不会跨设备同步。
- AI 返回格式与 reference 被验证，内容仍需要结合实际情况判断。
- 原仓库 CHATGPT_WRITE_TEST.md 保留；本次改动位于功能分支，供 PR review。
